# 环境搭建速查

## RISC-V 裸机工具链（pico-sdk 编译固件用）

官方来源：树莓派 `pico-sdk-tools` releases（riscv-toolchain-14）。下载并解压：

```bash
mkdir -p ~/toolchain && cd ~/toolchain
wget -c https://github.com/raspberrypi/pico-sdk-tools/releases/download/v2.0.0-5/riscv-toolchain-14-x86_64-lin.tar.gz
tar xzf riscv-toolchain-14-x86_64-lin.tar.gz -C ~/toolchain
```

要点：

- 压缩包解压后**顶层就是 `bin/`**（内含 `riscv32-unknown-elf-gcc` 等），不用再进子目录；
- 验证：`ls ~/toolchain/bin/riscv32-unknown-elf-gcc`；
- pico-sdk 通过 `PICO_TOOLCHAIN_PATH` 找编译器，可接受的三元组：`riscv32-pico-elf` / `riscv32-unknown-elf` / `riscv32-corev-elf` / `riscv-none-elf`（本工具链是 `riscv32-unknown-elf`）；
- 本机安装位置：`/home/developer/toolchain` → `export PICO_TOOLCHAIN_PATH=/home/developer/toolchain`；
- GitHub 直连可能很慢：可以用加速镜像，但下载后务必确认 `riscv32-unknown-elf-gcc` 存在（最好核对 sha256）；
- 压缩包约 850MB，解压完成后可以删掉省空间（`rm ~/toolchain/riscv-toolchain-14-x86_64-lin.tar.gz`）。

## 完整构建环境（本机现状，2026-08-21）

| 项 | 值 |
|---|---|
| PICO_SDK_PATH | `/home/developer/raspberrypi/pico-sdk`（2.3.0） |
| PICO_TOOLCHAIN_PATH | `/home/developer/toolchain` |
| PICO_PLATFORM | `rp2350-riscv` |
| PICO_BOARD | `rp2350a_minimal`（自定义，仓库 `boards/`） |
| PICO_BOARD_HEADER_DIRS | `<仓库>/boards` |
| 内核交叉编译器 | `riscv64-linux-gnu-gcc`（S2 编内核用，系统自带 /usr/bin） |
| QEMU | `qemu-system-riscv32`（10.2.1） |
| 其他工具 | picotool 2.3.0、openocd、dtc、cmake、ninja |
| 构建入口 | 仓库根 `make`（封装 cmake + ninja） |

标准构建命令（等价于 `make`）：

```bash
cd /home/developer/iotahydrae/rp2350-linux
PICO_TOOLCHAIN_PATH=/home/developer/toolchain \
cmake -DPICO_SDK_PATH=/home/developer/raspberrypi/pico-sdk \
      -DPICO_PLATFORM=rp2350-riscv \
      -DPICO_BOARD=rp2350a_minimal \
      -DPICO_BOARD_HEADER_DIRS=$(pwd)/boards \
      -B build -G Ninja
ninja -C build
```

S2 内核 QEMU 测试脚本：`s2/run-qemu.sh`（`-bios none` + earlycon/console 已配好；退出 Ctrl-A X）。
