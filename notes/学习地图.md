 ⑭ **GDB 读 PIE 内核数据符号必须加运行偏移**（2026-08-31 实证）：本工程 vmlinux 链接基址 **0x00000000**（PIE，自重定位到 0x11000000），nm/符号表地址全是 `0x00xxxxxx`；**GDB 按链接地址读数据会全读到 0（假象）**。正确运行时地址 = 符号地址 + 0x11000000（如 `dbg_xh3irq_trap_count` 链接 0x002c424c → 运行时 0x112c424c）。`scripts/pc-locate.sh` 已自行减偏移处理；GDB 手读数据要么 `x/wx <link+0x11000000>`，要么 `add-symbol-file vmlinux 0x11000000`（**不是 0x11001000**——GDB 按 .text 段首做基准，给 0x11001000 会多移 0x1000 读错）。**最稳兜底**：显式地址 + 类型强转，如 `set $uap = *(struct uart_amba_port **)0x112c5ab4`（amba_ports 运行时地址），再 `p $uap->...`（GDB 只从调试信息取类型，不受符号偏移影响）。**S4-04 计数器第一次读全 0 就是这个坑，不是 handler 没跑。**
 ⑮ **S4-04 TX 楔死根因收窄（2026-08-31）**：正确地址读计数器（trap_count=13、irq33_dispatch=13、loop_iters=26、last_next=NOIRQ、watchdog=0）→ **每次 trap 只分发一次 irq33 且干净退出，不是分发循环空转**；13 次 ≈ 敲字回显 + 少量 TX（fifosize=32 → 每 trap 最多 16 字符，SBSA 走 line 3170 固定 32）。楔死现场：IMSC=0x50（**TXIM 被清**、RXIM+RTIM 还在）、mip=0、CPU 在 arch_cpu_idle。**结论：pl011_stop_tx 清了 TXIM 后没再开，kfifo 有数据卡死**。判据链：`uart_tx_stopped = tty->flow.stopped || port->hw_stopped`；`__start_tty` 在 `tco_stopped` 未清时拒绝重启 → **流控死锁候选**（XOFF 0x13 默认 IXON / 输入缓冲满 tco_stopped / hush 卡在 cat 写没人读输入）。**下一步（免重编）**：GDB `add-symbol-file vmlinux 0x11001000` 修偏移后，读 `amba_ports[0]->port.hw_stopped`、`tty->flow.stopped/tco_stopped`、`receive_room`、`xmit_fifo.in/out` → 区分 XOFF 停 / 缓冲满死锁 / 其他。

 ⑰ **S4-04 根因实锤 + 修复（2026-08-31）**：定时器快照实锤：`meicontext_snap=0x88000` → **PREEMPT=8**（handler 外应为 0）、NOIRQ=1；`meintext_snap=0x84` → MEINEXT 仍显示 irq 33 可处理（PPREEMPT=0 不挡）；`trap_count` 停住不再涨。机制：Xh3irq 按"**优先级 ≥ PREEMPT 才允许打断内核**"——PREEMPT 卡 8 → irq 33 永远到不了内核，但 MEINEXT（用 PPREEMPT）还显示它，驱动状态全健康。**根因**：S3-03 的 MEICONTEXT 保存/恢复不完整——C handler 里恢复 MRETEIRQ=1 后，真正的 mret 要等 handle_arch_irq 返回 + 内核通用 IRQ 退出路径，**这段路径上的 PSRAM AMO 锁指令（spinlock）fault → 模拟器 trap → 非 MEIP trap 清 MRETEIRQ → mret 不弹栈 → PREEMPT 卡 8**。对照 pico-sdk 软分发：它的 MEICONTEXT 恢复在汇编尾部紧贴 mret，中间无 trap 源。**修复（临时未提交）**：不依赖硬件 mret 弹栈——handler 尾部 `chained_irq_exit` 后直接 `csr_write(MEICONTEXT, NOIRQ)`（PREEMPT=0/MRETEIRQ=0/NOIRQ=1 的 handler 外干净态；CSR 写本身会恢复 CLEARTS 存的 MTIE/MSIE）。**待真机验证**：cat /proc/meminfo 反复跑不再楔死；通过后清理调试插桩、提交正式修复。
