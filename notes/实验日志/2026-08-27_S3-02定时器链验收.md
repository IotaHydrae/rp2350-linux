# S3-02 定时器链验收（2026-08-26 ~ 08-27）

> 板子：自研 RP2350A-Minimal（16MB flash / 8MB PSRAM / UART0 GP16-17 @115200）
> 结论：✅ S3-02 验收通过——init_IRQ panic 消失、jiffies 动、启动推进到无 rootfs 的 VFS panic（新断点）

## 2026-08-26 首烧（驱动 v1：普通 request_irq）

现象：日志停在 `sched_clock: 64 bits at 1000kHz`，`rp2350-timer: timer running` 打不出来。

根因：`riscv,cpu-intc` 的中断全是 **percpu 中断**（`irq_set_percpu_devid` + `handle_percpu_devid_irq`），驱动用普通 `request_irq` 语义不匹配，卡在中断注册。

修复：改 `request_percpu_irq` + `DEFINE_PER_CPU` clockevent + `enable_percpu_irq`（照 timer-clint.c 写法）。

## 2026-08-26 二烧（percpu 修复后）

现象：`timer running at 1000000 Hz` 出来、时间戳推进，但日志停在 `printk: legacy bootconsole [pl11] disabled`，串口静默。

根因：`CONFIG_VT=y` → VT 注册 dummy console（tty0）→ printk 注册第一个非 boot console 时禁用 bootconsole（earlycon）→ 输出通道断了（系统其实还在跑）。

修复：defconfig 临时禁 `CONFIG_VT`（用户提醒 VT 后续可能被 framebuffer console 依赖，回头考虑只禁 `CONFIG_DUMMY_CONSOLE` 或走 S3-04 真 console）。

## 2026-08-26 三烧（禁 VT 后）

现象：日志推进到 `Mountpoint-cache hash table entries` 后**必现卡死**（复位多次复现），时间戳停在 0.049571。

## 2026-08-27 GDB 抓现场

```text
pc (/32): 0x1108b7cc
   0x1108b7b8:  li      a5,1
   0x1108b7ba:  li      a4,-1
   0x1108b7bc:  addi    a1,a0,84
   0x1108b7c0:  lr.w    a3,(a1)
   0x1108b7c4:  beq     a3,a5,0x1108b7d2
   0x1108b7c8:  add     a2,a3,a4
=> 0x1108b7cc:  sc.w.rl a2,a2,(a1)
   0x1108b7d0:  bnez    a2,0x1108b7c0
```

定位：`0x1108b7cc - 0x11000000 = 0x8b7cc` → System.map `0008b7b8 T deactivate_super` → `atomic_dec_and_test(&s->s_active)` 的底层 `arch_atomic_fetch_add_unless(v, -1, 1)`。

根因：arch/riscv/include/asm/atomic.h 里 4 个"有条件原子操作"（fetch_add_unless / inc_unless_negative / dec_unless_positive / dec_if_positive）用 **LR/SC** 实现。RP2350 排他监视器只认 SRAM（手册 2.1.6），PSRAM 上 `sc.w` 静默失败 → 循环永不退出。S3-01 只救了 cmpxchg（amocas.w），没救这几个。

修复：这 4 个操作在 `CONFIG_RISCV_AMO_EMULATION` 下改写为 `arch_cmpxchg`（amocas.w）循环 → AMO 会 fault → 模拟器兜底。反汇编确认 `deactivate_super` 生成 `amocas.w.aqrl`。

## 遗留（记录在案）

- `Warning: unable to open an initial console`：无真 console（ttyAMA0），S3-04 修。
- defconfig 禁了 `CONFIG_VT`（临时的）：S3-04 真 console 落地后应恢复；或先改成只禁 `CONFIG_DUMMY_CONSOLE`。
- Xh3irq 外设中断：S3-03 做。
- 64 位原子（`CONFIG_GENERIC_ATOMIC64` 走 cmpxchg64 LR/SC 路径）：本次未触发；若后续撞到，需把 rv32 的 64 位 cmpxchg 也迁到 amocas.d 并扩展模拟器。
