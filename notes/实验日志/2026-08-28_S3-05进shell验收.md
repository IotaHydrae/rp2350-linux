# 2026-08-28 · S3-05 进 shell 验收

板子：RP2350A-Minimal（自研）；内核 sha `e2984005`（含 Xh3irq MEICONTEXT 修复）；工程 `s3/05_shell/`。

```
[    1.575523] Run /init as init process

```

## 结论

- initramfs 编进内核 → rootfs 解包 → `/init`（手搓 bFLT）作为 PID 1 执行，VFS panic 消失。
- `/init` 挂 devtmpfs → open /dev/ttyAMA0 → termios raw → `# ` 提示符。
- 真实 UART RX 中断链全通：`hello` 回显 + `Hello, world!`；未知命令提示；提示符循环。
- **项目终点达成：板子串口进 shell。**

## 本关修的三个 bug（详见学习记录）

1. `arch_atomic_dec_unless_positive` 返回值写反（首次 exec 触发 ETXTBSY）。
2. pack-bflt.sh bFLT 头偏移 32→64 + ELF `-no-pie`（入口落零 SIGILL）。
3. Xh3irq chained handler 缺 MEICONTEXT 保存/恢复（首个字符后外部中断全屏蔽）。
