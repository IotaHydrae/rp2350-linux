# 2026-08-28 · S3-04 真 console 收尾验收

板子：RP2350A-Minimal（自研）；内核 sha `c9b844e9`（DEBUG_INFO 版）；工程 `s3/04_console/`。

## 过程

1. 烧 DEBUG_INFO 内核：日志末尾停在 VFS panic（S3-05 前预期终点）；`log-analyze.sh` 显示 函数名 + 源文件:行号。
2. DTB bootargs 加 `console=ttyAMA0`：`Kernel command line` 生效，日志与之前无变化（押注命中——VT 关着时锁定不产生可见差异）。
3. defconfig 开 `CONFIG_VT=y`：新出现 `Console: colour dummy device 80x25`，全程无 `legacy console [tty0] enabled`，ttyAMA0 正常接管。
4. sbsa-uart 定案：长期用（用户拍板）。

## 结论

- `console=` 锁生效：VT 恢复但 dummy 抢不走日志（阳性标记 = 新出现的 dummy device 行；阴性证据 = 无 tty0 enabled）。
- enabled/disabled 各两遍 = 同一记录被两个 console 各写一次（正常广播，非 bug）。
- VFS panic 是 S3-05 前预期终点。
