# S1 假镜像闭环首次联跑（RP2350A-Minimal）

- 日期：2026-08-21
- 板子：自研 RP2350A-Minimal
- 目的：验证 bootloader 拷贝假镜像到 PSRAM 并跳转的完整闭环
- 结论：闭环 PASS——拷贝、指令取指、数据读三个方向同时验证

## 烧假镜像时的报错（修法见 S1 复盘文小坑）

```text
picotool load -fv -o 0x10000 build/fake-image.bin
ERROR: File to load contained an invalid memory range 0x00010000-0x00010175
```
