# 2026-08-28 · S4-01 shell 调用外部程序验收

板子：RP2350A-Minimal（自研）；内核与 S4-00 相同（无内核改动）；工程 `s4/01_exec-hello/`；只烧 rootfs（分区 2）。

## 验收日志（UART0，GP16/17，115200）

```
S4-01 shell exec /bin/hello
# hello
Hello, world!
#
# abc
unknown command
#
```

## 结论

- NOMMU 进程创建链全通：shell 解析 hello → vfork（clone CLONE_VM|CLONE_VFORK|SIGCHLD）→ 子进程 execve /bin/hello → 父 waitid(WEXITED) 回收 → 提示符回归。
- /bin/hello 是 rootfs 里第二个手搓 bFLT，独立进程打印 `Hello, world!`（shell 里已无此字符串）。
- rootfs 独立烧录复用：只烧分区 2 完成整关。

## 过程中踩的架构坑

1. **riscv32 无 wait4**：asm-generic 的 `__NR_wait4 260` 只在 time32 或 64 位下进表，riscv32 用 waitid(95)。（首次调用返回 -ENOSYS）
2. **waitid options 必须显式 WEXITED**：传 0 返回 -EINVAL，父进程不等待、提示符抢跑。
