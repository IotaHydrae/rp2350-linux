# S1 分区表版联跑（RP2350A-Minimal）

- 日期：2026-08-21
- 板子：自研 RP2350A-Minimal
- 目的：验证 picobin 分区表版 bootloader（partition 0 = FAKE @ 64K）
- 结论：PASS——bootloader 从分区表定位镜像、拷贝、跳转，假镜像照常运行

## 第一次 flash-fake 报错（设备侧状态问题）

```text
picotool load -fv -p 0 build/fake-image.bin
ERROR: There is no partition table on the device
```

原因：分区表其实已随 bootloader UF2 烧进设备（字节级比对确认 `.pt` 段在 UF2 里，`d3 de ff ff 0a 08...`），但设备需要重启后重新扫描 flash；picotool 读的是设备当前的分区表。重启再进 BOOTSEL 后正常。

## 重启后成功

```text
picotool load -fv -p 0 build/fake-image.bin

  00010000->00020000

```
